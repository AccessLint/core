Key findings

  • @accesslint/core is 12× faster at median (why?)
  • High agreement (80%+) on major criteria like color-contrast, image-alt, and link-name (96%)

Methodology

  • Sample: 5,000 origins from the Chrome UX Report, seeded random sample
  • Runner: Chromium 145 via Playwright 1.58, headless, on GitHub Actions (ubuntu-latest)
  • axe-core: v4.11.1, default configuration (no custom rules enabled). Only violations are compared
  • @accesslint/core: latest, default configuration
  • Per-site timeout: 15 s (navigation + audit), 5 concurrent pages per shard, 10 shards
  • Source: accesslint/accesslint-bench
